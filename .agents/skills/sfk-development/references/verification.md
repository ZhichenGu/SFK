# 按改动选择验证

本表是风险定位参考，只执行与此次改动有关的检查。工具不可用时记录未验证项；模拟结果不代表云端通过。

## 本地基础检查

- 检查变更差异和 JavaScript 语法。`node --check <file.js>` 可检查独立脚本；`index.html` 内联脚本需先提取到临时文件再检查，不能直接按 JS 检查 HTML。
- 需要浏览器时在仓库启动本地静态服务，例如 `python3 -m http.server 8000 --bind 127.0.0.1`。按工具返回地址访问，结束后停止本次启动的服务。
- 静态服务仍会加载真实 `config.js`。需要本地持久化测试时，在隔离副本或浏览器加载应用前将 SFK_CONFIG 设为空，确认无生产请求；不要为了测试提交配置改动。

## 行为检查

| 改动 | 有意义的验证 |
| --- | --- |
| 保存或记录切换 | 延迟保存期间继续输入、返回管理或切换老师；结果不落到别的记录，未保存内容可恢复；自动与手动保存不互相覆盖 |
| 并发更新 | 两端加载同一 revision，一端保存或签名后另一端保存；显示冲突，保留服务端签名，不覆盖重试 |
| 学生提交 | 空签名、处理中图片、重复点击、已有签名、过期链接、提交响应丢失；最终展示服务端已接受的签名 |
| 签名处理 | 文字、画笔、上传图片；压缩后的实际图片字节不超 16384 且可辨认；重传或清除后迟到的图片不复活 |
| 批量或 OCR | 全成功、全失败、部分成功、重试、刷新恢复；已成功项不重复创建，失败输入和记录 ID 可恢复；复制失败不显示成功 |
| A4 或导出 | 长中文、空项、跨日时间、双签名、字体就绪前后；预览、打印、单份 PNG 与 ZIP 内 PNG 内容一致，无截字或缺签名 |
| 移动界面 | 约 375px 宽度与桌面宽度下，操作按钮、长姓名、长链接、签名画布可见可用，主要内容无横向溢出 |
| SQL 校验 | 有效记录、缺失或错误类型、16 KB 边界、revision 冲突、签名幂等与链接失效规则；在隔离数据库验证实际 SQL 行为 |

测试使用合成学生与签名。真实环境写入须有授权并明确项目；不要用公开可读推断写入 RPC 已部署。完成说明标明检查环境、结果和未覆盖的关键路径。
